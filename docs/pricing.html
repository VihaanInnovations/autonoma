Enterprise Features

What is SSO?

Single Sign-On allows users to authenticate using your existing identity provider. Supports SAML 2.0 and OIDC/OAuth2 protocols. Works with Okta, Azure AD, Google Workspace, and other providers.

What compliance standards are supported?

  • SOC2 (Type I and Type II)
  • GDPR (General Data Protection Regulation)
  • OWASP Top 10
  • PCI-DSS (Payment Card Industry Data Security Standard)
  • HIPAA (for healthcare codebases)

Technical

What are the system requirements?

  • CPU: x86-64 or ARM64
  • RAM: 4GB minimum (8GB recommended for local LLM)
  • Disk: 2GB for models and dependencies
  • OS: Windows 10+, macOS 10.15+, Linux (Ubuntu 20.04+)
  • No GPU required (CPU inference supported)

What programming languages are supported?

  • Python
  • JavaScript/TypeScript
  • Java
  • C/C++
  • Go
  • Rust
  • More languages coming soon
