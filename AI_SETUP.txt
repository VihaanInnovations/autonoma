========================================
   OPTIONAL: Enable Local AI (Ollama)
========================================

Autonoma Pilot Edition includes a built-in "L5 Autonomous Mode" that can fix code using AI. 
This works 100% locally and offline, but requires you to install a Local LLM runner.

If you skip this, Autonoma will still work using "Native Heuristics" (Regex-based fixes), 
which is faster but less capable for complex logic issues.

----------------------------------------
Step 1: Install Ollama
----------------------------------------
1. Download Ollama from: https://ollama.com/
2. Install it on your machine.
3. Ensure it is running (you should see the llama icon in your tray).

----------------------------------------
Step 2: Pull the Code Model
----------------------------------------
Open your terminal (PowerShell or CMD) and run:

    ollama run qwen2.5-coder

(This will download the ~4GB model. Wait for it to finish and give you a prompt.)
Type "/bye" to exit the chat, but keep the Ollama app running.

----------------------------------------
Step 3: Verification
----------------------------------------
Restart Autonoma Daemon:
    ./run_pilot.ps1

You should no longer see "ConnectError" in the logs! 
Instead, you will see "Engaging Qwen LLM..." when fixing bugs.

Enjoy your Local AI Code Engineer! 🚀
